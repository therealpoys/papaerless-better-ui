# apps/mobile – Handy-App

- **Kamera-Scan** mit Kantenerkennung, Zuschnitt, Mehrseiten-Scan → PDF
- "Teilen mit…" aus anderen Apps (PDFs, Fotos, Mails)
- Upload-Queue (funktioniert auch offline, lädt später hoch)
- Schnelles Bestätigen der KI-Vorschläge (Swipe / 1 Tap)
- Push-Benachrichtigung, wenn ein Dokument verarbeitet wurde
